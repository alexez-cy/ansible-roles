# Ansible Roles

A collection of reusable Ansible roles for automating infrastructure provisioning, configuration, and day-to-day operations.

This repository contains roles developed from production environments, homelab projects, and continuous learning. The focus is on creating modular, idempotent, and reusable automation that follows Ansible best practices.

---

## Goals

- Automate infrastructure configuration
- Build reusable Ansible roles
- Promote consistent system configuration
- Reduce manual operational tasks
- Maintain production-quality automation

---

Each role includes its own documentation, variables, defaults, handlers, and examples.

---

## Design Principles

- Idempotent execution
- Modular role design
- Minimal hardcoded values
- Configurable through variables
- Well-documented defaults
- Production-oriented automation
